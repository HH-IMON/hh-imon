# Set up your GitHub profile — HH-IMON

## Upload the profile

1. Extract `HH-IMON-github-profile-kit.zip` on your computer.
2. Open your public profile repository: `https://github.com/HH-IMON/HH-IMON`.
3. If it does not exist, create a **public** repository named **HH-IMON**, exactly matching your username.
4. Choose **Add file → Upload files**. Upload **README.md** and the entire **assets** folder from the extracted kit into the repository root. Preserve the folders and filenames.
5. Commit the changes and open `https://github.com/HH-IMON`.

The repository root should contain `README.md` beside `assets/`. Do not upload the ZIP itself or place everything inside an extra `HH-IMON-github-profile-kit/` folder in the repository.

`SETUP.md` is only an installation guide; you do not need to upload it.

## If a picture does not show

Check that the `assets/` folder is beside `README.md` and the spelling and capitalization of the filenames match. All image paths in the README begin with `./assets/`.
